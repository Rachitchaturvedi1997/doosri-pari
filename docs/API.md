# Doosri Pari API

Generated by `python -m python.tools.gen_api_doc`. **283 operations.** Do not edit by hand.

- REST + JSON. Auth is `Authorization: Bearer <access token>` from `/auth/verify`, `/auth/google` or `/auth/apple`; refresh with `/auth/refresh`.
- Times are epoch seconds (float). Money is integer paise.
- Errors are always `{"detail": "...", "errors": [{"field", "msg"}]}`.
- Every response has `X-Request-ID`; quote it when reporting a problem.
- Nothing personal is cacheable: responses carry `Cache-Control: no-store` except `/app/config` and media links.
- Live updates: connect a WebSocket to `/ws?token=<access token>`; events are hints, REST is the source of truth.
